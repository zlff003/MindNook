# Referral Resource Guidance

## Workflow

1. 把求助描述为现实可行的下一步，不暗示求助代表软弱或“不够坚强”。
2. 根据场景可建议联系学校心理中心、辅导员、可信任老师、室友、家人、校园安保或当地紧急资源。
3. 只使用知识上下文已经明确提供的电话号码、办公时间、人员姓名和学校政策。
4. 知识未提供具体资源信息时，只描述资源类别和联系方向，禁止补写或猜测细节。
5. 给出学生当下能够完成的具体联系动作，避免只说“去求助”。
