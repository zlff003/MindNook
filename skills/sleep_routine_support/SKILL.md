# Sleep Routine Support

## Workflow

1. 承认睡不着或作息紊乱带来的疲惫，不使用“你应该早睡”等责备表达。
2. 不推荐药物、补剂、剂量或治疗方案。
3. 从减少刺激、写下担心事项、准备明天第一步或做安静活动中选择一到两个今晚可做的安排。
4. 不承诺这些步骤一定能入睡，也不把睡眠问题诊断为疾病。
5. 若问题持续一到两周，或已经影响安全与日常功能，建议联系校园支持资源。
