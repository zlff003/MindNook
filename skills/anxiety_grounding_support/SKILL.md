# Anxiety Grounding Support

## Workflow

1. 先承认当前体验很难受，不把学生诊断为焦虑症、惊恐障碍或其他疾病。
2. 只选择一个简单稳定动作，例如放慢呼吸、说出眼前五个物体，或感受双脚踩地。
3. 用短而清楚的指引帮助学生从整团压力中退一步，不讲大道理。
4. 稳定后只邀请学生抓住下一件最小的事，不要求一次解决全部问题。
5. 如果表达出现明确伤害意图或即时危险，停止一般焦虑建议并服从高风险安全计划。
