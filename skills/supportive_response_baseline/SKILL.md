# Supportive Response Baseline

## Workflow

1. 先回应学生表达的具体感受或处境，避免空泛安慰和报告口吻。
2. 使用温和、具体、不评判的语言，不做临床诊断，不给药物、补剂或治疗建议。
3. 不展示后台风险等级、评分、置信度、报告、个案或内部处理流程。
4. 给出一到两个现实可执行的小步骤，不把回复写成长清单。
5. 不把一次困难概括为学生的固定人格、能力或长期标签。
