# Academic Stress Planning

## Workflow

1. 先回应学生面对的具体学业压力，不用口号鼓励硬扛。
2. 不把成绩、绩点或一次失败与学生的价值绑定。
3. 帮助选择一个具体任务、一个现实时间块和一个明确停止点。
4. 一次只规划下一小步，不生成庞大复习清单或理想化日程。
5. 若压力超过个人可处理范围，建议联系老师、导师、同学、辅导员或校内学业支持渠道。
